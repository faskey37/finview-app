## 🚀 Features

- **📊 Financial Dashboard** - Real-time overview of your finances
- **🤖 AI-Powered Insights** - Personalized savings tips and recommendations
- **🌱 Carbon Footprint Tracking** - Track environmental impact of purchases
- **💰 Budget Management** - Create and track budgets across categories
- **🎯 Financial Goals** - Set and achieve savings goals
- **📈 Investment Tracking** - Monitor investment portfolios
- **📱 Bank Account Integration** - Connect multiple accounts
- **🔒 Bank-Level Security** - 256-bit encryption, SOC 2 compliant
- **📧 Email Notifications** - Weekly summaries and alerts
- **📤 Data Export** - Complete backup of your financial data

## 📋 Prerequisites

- Node.js 18.x or higher
- npm or yarn package manager
- Firebase account (for authentication and database)
- Razorpay account (for payment processing)
- SMTP email service (for notifications)

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Authentication**: Firebase Auth
- **Database**: Firestore
- **Payments**: Razorpay
- **Email**: Nodemailer with SMTP
- **Animations**: Framer Motion
- **Charts**: Recharts
- **Forms**: React Hook Form + Zod
